# Generate Install Configuration — Disconnected / Air-Gapped

## Additional install-config.yaml Fields

A disconnected installation requires these extra fields in `install-config.yaml`, regardless of installation method:

```yaml
# Mirror registry CA (required if self-signed)
additionalTrustBundle: |
  -----BEGIN CERTIFICATE-----
  <paste mirror registry CA cert here>
  -----END CERTIFICATE-----

# Image content sources (tells the cluster where to pull images)
imageDigestMirrors:
  - mirrors:
      - registry.example.com:8443/openshift/release-images
    source: quay.io/openshift-release-dev/ocp-release
  - mirrors:
      - registry.example.com:8443/openshift/release
    source: quay.io/openshift-release-dev/ocp-v4.0-art-dev
```

> **Note:** In OpenShift 4.13+, `imageDigestMirrors` replaces the older `imageContentSources` field. Both are accepted, but `imageDigestMirrors` is preferred.

## Pull Secret

Use the merged pull secret that includes mirror registry credentials. Do **not** include Red Hat registry credentials in the cluster pull secret if the cluster has no internet access — it will cause image pull errors.

```yaml
pullSecret: '<MERGED_PULL_SECRET_WITH_MIRROR_REGISTRY_CREDS>'
```

## Apply IDMS and CatalogSource Post-Install

After the cluster is up, apply the manifests generated by `oc-mirror`:

```bash
# ImageDigestMirrorSet — tells the cluster to redirect image pulls
oc apply -f oc-mirror-workspace/results-*/imageDigestMirrorSet.yaml

# CatalogSource — enables OperatorHub from the mirrored catalog
oc apply -f oc-mirror-workspace/results-*/catalogSource.yaml
```

### Or Embed in Install Manifests

For IPI and UPI, copy the IDMS and CatalogSource manifests into the `openshift/` directory before running the installer:

```bash
cp oc-mirror-workspace/results-*/imageDigestMirrorSet.yaml ~/ocp-install/openshift/
cp oc-mirror-workspace/results-*/catalogSource.yaml ~/ocp-install/openshift/
```

For the Agent-based Installer, place them in the same directory before generating the ISO:

```bash
cp oc-mirror-workspace/results-*/*.yaml ~/agent-install/openshift/
```

## Disable Default OperatorHub Sources

The default catalog sources point to internet-hosted catalogs. Disable them in disconnected environments:

```bash
oc patch operatorhub cluster --type merge \
  -p '{"spec":{"disableAllDefaultSources":true}}'
```

This is done automatically if you embed the CatalogSource in the install manifests.

## Disconnected Validation

```bash
# Verify image mirror is working
oc adm release info --registry-config=merged-pull-secret.json \
  registry.example.com:8443/openshift/release-images:4.22.0-x86_64

# Verify OperatorHub shows mirrored operators
oc get packagemanifest -n openshift-marketplace

# Verify no pods are stuck on ImagePullBackOff
oc get pods -A --field-selector=status.phase=Pending --no-headers
```
