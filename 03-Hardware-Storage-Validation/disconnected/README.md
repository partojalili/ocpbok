# Hardware and Storage Validation — Disconnected / Air-Gapped

This is a cross-cutting validation that applies to any platform type when the environment has no internet access.

## Mirror Registry Validation

- [ ] Mirror registry is deployed and running
- [ ] Mirror registry hostname resolves from all target nodes
- [ ] Mirror registry TLS certificate is valid (or CA is available for trust)
- [ ] Mirror registry has sufficient disk space (500 GB+ depending on operators mirrored)

```bash
# Test mirror registry connectivity
curl -sk https://registry.example.com:8443/v2/_catalog | jq .

# Check available space
df -h /opt/quay  # or wherever the registry data lives
```

## Mirrored Content Validation

- [ ] OpenShift release images mirrored for target version (4.22.x)
- [ ] Required Operator catalogs mirrored (ODF, logging, OADP, etc.)
- [ ] Additional application images mirrored (if required for POC workloads)

```bash
# Verify release images exist in the mirror
oc adm release info --registry-config=merged-pull-secret.json \
  registry.example.com:8443/openshift/release-images:4.22.0-x86_64

# List mirrored operators
oc-mirror list operators --catalog=registry.example.com:8443/redhat/redhat-operator-index:v4.22
```

## Pull Secret Validation

- [ ] Merged pull secret includes mirror registry credentials
- [ ] Pull secret does NOT include Red Hat registry credentials (they will cause pull errors in air-gapped)

```bash
# Verify mirror registry auth is present
cat merged-pull-secret.json | jq '.auths["registry.example.com:8443"]'
```

## CA Certificate Validation

- [ ] Mirror registry CA certificate file is available
- [ ] CA certificate is trusted on the provisioning host

```bash
# Verify CA trust
openssl s_client -connect registry.example.com:8443 -CAfile registry-ca.crt < /dev/null 2>/dev/null | grep "Verify return code"
# Expected: Verify return code: 0 (ok)
```

## IDMS and CatalogSource Manifests

- [ ] `ImageDigestMirrorSet` YAML generated by oc-mirror
- [ ] `CatalogSource` YAML generated by oc-mirror
- [ ] Manifests are ready to embed in install directory or apply post-install

## Data Transfer Plan

For fully air-gapped environments, validate the transfer method for mirrored content:

- [ ] Transfer medium available (portable drive, secure file transfer)
- [ ] Transfer medium has sufficient capacity for the mirror output
- [ ] Transfer procedure tested end-to-end (connected host → medium → disconnected host → registry)
